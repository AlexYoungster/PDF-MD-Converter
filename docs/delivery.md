# 独立项目与交付范围

本项目从历史工作目录中的 `document_converter` 提取。源目录与历史结果继续保留，独立目录无需访问它们即可安装、运行和测试。项目名为 **PDF-MD-Converter**，发行包名 `pdf-md-converter`，Python 包名保留为 `document_converter`。

## 纳入内容

- 17 个转换器 Python 模块：转换入口、PDF 页面、正文、印刷目录、表格、脚标、分数、单位、分卷、刷新和独立校验。
- 转换器测试及原创示例生成器。
- 根安装配置、使用指南、架构、数据接口、边界和贡献文档。
- 空的输入/输出目录占位文件。

不依赖旧的 `condition_extractor` 包、规则筛选、语义恢复、知识卡片、SQLite 知识库或历史研究下载。旧项目的 `condition-extractor doc2md` 包装入口不进入独立包。

科学计数法中印刷的 `x` / `X` 不再被替换成 `×`，仅消除排版空格，避免新增来源字符差异。印刷目录在真实文档复核后改为按空间位置重建，修复条目及页码错配风险和层级丢失。命令显示名称同步更新；历史 review 不改标为已确认。私有文档回归测试在本项目根目录查找并打标，缺少材料时跳过。

## 本地数据

`origin/` 放用户原文，`output/` 放转换及检查结果，两者默认被 `.gitignore` 排除。`.venv/`、`dist/`、缓存、模型和临时文件也排除。用户为验证而新放入的文档仍属于本地数据，不自动进入源代码交付包。

程序输出包含原文件副本和摘录。对外分享时自行确认输入文档的分发权限。本项目没有附带历史商业手册或其转换语料，也未替维护者选择代码许可证。
