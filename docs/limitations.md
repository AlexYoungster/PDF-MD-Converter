# 能力边界

## PDF

- 主要依据原生文字层、字形坐标、矢量网格和线条；破损或缺失文字层不能靠字符守恒证明正确。
- 段落恢复主要在页内进行。复杂多栏、图形标签、独立公式和跨页续段仍可能需要复核，当前不自动合并跨页段落。
- 原生印刷目录通过引导点、页码列及基线识别；无明确标题时至少需要四组配对，有标题时至少需要两组稳定条目。证据不足回到正文路径；扫描、斜排、右向左文字及不规则混排目录不承诺自动重建。不确定片段按位置保留并标记复核。
- 几何表格检测不能保证发现所有无线表、斜线表或扫描图像中的表格。非矩形、冲突网格保留图像、坐标文字或降级结果。
- 图像保留针对已检测表格及低文本/按选项保存的页面，不承诺所有正文插图都会自动独立导出；原 PDF 随包保留。
- 数字分数需要明确矢量线和完整数字依据；符号分式、嵌套分式、复杂公式不会通过猜测改写。
- 字符守恒只检验来源字形的分配和数量，阅读顺序、脚标绑定与数学意义需额外证据。
- 输出含 HTML 和相对图片引用。只支持纯 Markdown 的阅读器可能无法完整渲染合并单元格或脚标。

## OCR

OCR 是可选的 RapidOCR CPU 候选识别，不是大模型多模态重写。原文与 OCR 不一致时保留候选和复核信息。启用 OCR 不意味着扫描表格已获得与原生网格相同的结构保证。转换器与独立检查器使用不同的 OCR 模式集合，参见根 README。

## 其他格式

| 输入 | 已保留的结构 | 边界 |
|---|---|---|
| DOCX | 正文顺序、标题样式、表格、节页眉页脚 | 浮动对象、修订和批注以源文件为准；复杂合并表不等同 PDF 网格恢复 |
| PPTX | 幻灯片、文字形状、表格、备注 | 形状按位置近似排序；图片、图表和原版式留在源文件 |
| XLSX | 工作表、公式字符串、单元格行列、合并区说明 | 不计算公式，不还原全部格式、图表或合并布局 |
| HTML | 标题、段落、列表、引用、表格、链接和图片引用 | 不转换脚本和样式；外部图片保持引用 |
| CSV | CSV 行列 | 不推断类型和格式 |
| TXT / MD | UTF-8 文本；MD 主体保留并增加来源链接 | 非 UTF-8 输入按替代字符读取，需用源附件核对编码 |

未支持的类型明确报错。无卷标题的 PDF 只生成全文；连续卷号不明确时拒绝猜分卷。需要密码的 PDF 应先提供可访问副本。

## 稳定性与验收

原文、图片、审计和分卷必须作为一套产物管理。可捕获写入异常使用回滚，但没有并发写锁和断电恢复协议。同一输出包串行处理。

自动检查的 error 和 review 分开报告。顺序见证冲突可能来自原生流、复杂公式或真实错序；需查看原图后才能确认。报告中没有 error 不等于已完成专家复核或全书 OCR。
